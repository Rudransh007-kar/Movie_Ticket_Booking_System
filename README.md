# Movie Ticket Booking System

## System Design Project

The **Movie Ticket Booking System** is a C++-based System Design project developed to demonstrate the application of **Object-Oriented Programming (OOP)** principles in a real-world booking scenario.

The primary objective of this project is to understand how a movie booking platform can be structured using well-defined classes, relationships, and modular components.

## Project Overview

The system provides a workflow for booking movie tickets. Customers can browse available movies and show timings, check seat availability, select their seats, complete the payment process, and generate their tickets.

The application also incorporates booking cancellation and validation mechanisms to prevent invalid seat selections and duplicate bookings. Different payment methods and payment failure scenarios are handled to make the system more representative of a real-world ticket booking application.

## Key Features

* Display movie and show information
* Check real-time seat availability
* Support for Silver, Gold, and Platinum seating categories
* Booking of multiple seats in a single transaction
* Multiple payment options:

  * UPI
  * Credit/Debit Card
  * Cash
* Payment failure and validation handling
* Automatic ticket generation
* Booking cancellation functionality
* Detection of already reserved seats
* Validation of invalid seat selections

## SOLID Principles

The design incorporates the following **SOLID principles**:

### Single Responsibility Principle (SRP)

### Open/Closed Principle (OCP)

### Liskov Substitution Principle (LSP)


DIP(Dependency Inversion Principle) has not been explicitly implemented in this project. Since this is a small academic project, direct object creation has been preferred to keep the implementation straightforward and easy to understand.
